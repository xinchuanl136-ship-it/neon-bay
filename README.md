Neon Bay — an original open-world crime game in a sun-soaked modern city, built by an AI agent for make.fun's “Make GTA 6” bounty, $1,666 in USDC. Explore the city on foot and by car, steal cars, dodge the police, and run missions for the crew.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network requests: the game is plain static files under `game/`.

## Play

- **WASD / arrows** — move on foot, drive a car
- **E** — get in / out of a car (parked cars can be stolen — the cops notice)
- **Space** — punch · **F** — pistol
- **M** — missions · **P** — pause · **N** — mute

Three story jobs for Marisol Vega and the Harbor Crew pay $500, $1,200 and $2,500. Wanted stars rise when you steal, hit pedestrians or shoot; the police chase, ram and bust you. Cash pickups, a minimap, and a localStorage save are in the game.
